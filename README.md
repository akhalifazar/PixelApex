# PixelApex

Transforms images from RAW files to JPEG and TIFF formats for photographers and graphic designers.

With PixelApex, you get a lightweight tool that stays out of your way.

**What you get**

- Transforms images from RAW files
- to JPEG and TIFF formats
- for photographers and graphic designers

## Key Features

- Transforms images from RAW files
- to JPEG and TIFF formats
- for photographers and graphic designers

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/PixelApex.git`
2. `cd PixelApex`
3. Install in editable mode: `pip install -e .`

## Configuration

PixelApex is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
